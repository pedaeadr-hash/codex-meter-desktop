# Identidade visual

`openai-blossom.svg` reproduz o simbolo OpenAI de 2025, criado pela OpenAI e obtido em:

https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg

O arquivo e descrito na origem como uma marca geometrica em dominio publico, mas continua sujeito
a direitos de marca. Neste projeto ele identifica somente a integracao direta com o Codex; nao indica
afiliacao ou endosso oficial da OpenAI.
